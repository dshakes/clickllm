Why this exists

Open models caught up. Migrations didn't.

A team paying $18K/month knows GLM-5.2 is MIT-licensed and probably good enough. They don't switch, because probably is not something you bet a production system on — and nothing turns "probably" into evidence.

How it works

Seven stages. One command.

Each stage is an agent with tools — conversational, resumable, able to skip ahead when the answer is already known. clickllm switch drives all seven and asks only when it genuinely can't decide.

① Observe

Swap one base_url. We capture traffic and redact PII before it touches disk. Useful day one as a cost dashboard.

② Distill · moat

Cluster prompts by task shape. Your recorded closed-model outputs become the incumbent baseline.

③ Fit

What runs on your silicon at the context and concurrency you actually use. MoE, GQA and MLA-correct.

④ Prove · the hero

Assertions → task graders → position-swapped judge, against your incumbent, per task cluster.

⑤ Deploy

Zero-config. Every knob derived, benchmarked, and reverted if it doesn't help on your hardware.

⑥ Cut over · moat

Shadow → canary → cut, gated on quality. Auto-rollback in under 10 seconds.

Columns are traffic-weighted. The incumbent is pinned at 100 — nobody cares about absolute quality, only whether switching is a downgrade. Regret sits above the fold, because the honest failure is what makes the wins credible.

Install

Every distribution channel you already use.

# no install — runs straight from the index
uvx clickllm fit --context 32k --concurrency 8
brew install dshakes/tap/clickllm
clickllm fit
pipx install clickllm
clickllm fit
docker run --rm ghcr.io/dshakes/clickllm:latest fit --json

# with GPUs, for planning against the host's real hardware
docker run --rm --gpus all ghcr.io/dshakes/clickllm:latest fit
cargo install clickllm-core --features cli
clickllm fit
git clone https://github.com/dshakes/clickllm && cd clickllm
uv run --python 3.13 python -m clickllm.cli fit
cargo test          # 61 Rust tests

Status

Pre-alpha, built in the open.

This page describes the target. Here is what actually runs today — stated plainly, because a roadmap dressed as a changelog is the fastest way to lose an engineer's trust.

Shipping

Stage ③ Fit — hardware profiler, MoE/GQA/MLA-correct solver, runtime recommendation, --explain.
Licence gate — refuses before bytes move; unknown licences fail closed.
Runtime trait — vLLM and llm-d render native config.

Not built yet

① Observe · ② Distill · ④ Prove · ⑤ Deploy · ⑥ Cut over · ⑦ Guard

Specified in full, with acceptance criteria and risk gates, in the implementation plan.

The risk we're most likely to get wrong

Grader quality is the product. A wrong equivalence verdict breaks a customer's production system. Mitigations are designed in — three-tier grading, position-swap debiasing, published judge–human agreement rates, and shadow mode as the real gate before any traffic moves. If stage ④ can't produce verdicts people trust, there is no product, and we'd rather find that out in month 4 than month 24.

About

Built on a thesis, not a hunch.

Fourteen competing products were researched across four layers before a line was written. The conclusion was that almost everything in this space already exists and is good — deployment is solved six times over — and that the migration itself is unowned. Every load-bearing decision, including the ones that reversed earlier ones, is recorded as an ADR.

Apache-2.0

A product about escaping lock-in cannot create lock-in. Eval sets export, generated config runs standalone.

Local-first

Zero telemetry. Nothing leaves your machine without an explicit command. Works fully air-gapped.

Auditable

--explain on every number. Judge model and human-agreement rate disclosed in every report.
